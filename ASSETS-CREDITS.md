before it is used or shipped. Anything under `web/` is served to every visitor,
i.e. **distribution**.

### LibreQuake licence breakdown

From `third_party/LibreQuake/docs/README-IMPORTANT-LICENCE-INFO`: "This project
contains files under multiple different licenses."

- **All models, textures and sounds: BSD-3-Clause** (`docs/COPYING`,
  "Copyright (C) 2019-2023 Contributors to the LibreQuake project"). Permissive;
  permits redistribution, including over the web, provided the licence and
  copyright notice are retained. **This is the part we intend to use as game
  content**, and it is suitable for redistribution in `web/`.
- **QuakeC, `progs.dat`, `pop.lmp`: GPL v2** (`docs/misc-docs/COPYING`).

So: use LibreQuake's **assets** under BSD-3, retaining `docs/COPYING` and the
copyright notice in `ASSETS-CREDITS.md`. If we ever ship their `progs.dat` or
QuakeC, GPL v2 applies instead.

### What we actually ship in `web/`

Built by `scripts/build_maps.sh`, `scripts/build_progs.sh` and
`scripts/build_models_wad.sh`; the page's content list is generated by
`scripts/gen_manifest.py` and checked by `tests/run_fte.js`.

| File in `web/id1/` | Built from | Licence |
|---|---|---|
| `our.wad` | LibreQuake `texture-wads/` PNGs, packed by `scripts/mkwad.py` into WAD2 miptexes quantised to `lq1/gfx/palette.lmp` | BSD-3-Clause |
| `gfx.wad` | LibreQuake `lq1/gfx.wad`, verbatim | BSD-3-Clause |
| `models.pak` | LibreQuake `lq1/progs/*.mdl` and `*.spr`, packed by `scripts/mkpak.py`. The list is read out of the compiled `qwprogs.dat` (the strings it precaches), not hand-written | BSD-3-Clause |
| `progs.dat`, `qwprogs.dat` | LibreQuake `qcsrc/` (id's QuakeC, GPL v2) compiled with fteqcc by `scripts/build_progs.sh`, exactly as LibreQuake's own `build.py` does | **GPL v2** |
| `quake.rc` | ours | ours |
| `maps/corridor.bsp` | our `maps/corridor.map` via ericw-tools qbsp/vis/light | ours |

The QuakeC is GPL v2, so `progs.dat`/`qwprogs.dat` are GPL v2 and our
derivative game code built on them must be GPL v2 too. `docs/misc-docs/COPYING`
carries that notice. Sounds are **not** shipped: the full sound set is 86 MB,
which is not acceptable for a web client, and a missing sound is a cosmetic gap
rather than a load failure.

We deliberately use `qwprogs.dat` (LibreQuake's deathmatch build) as the primary
progs: the single-player `progs.dat` also precaches all the monsters, which a
team shooter has no use for.

`palette.lmp` is LibreQuake's 256-colour Quake palette (a colour table, BSD-3),
not id's GPL `pop.lmp`.

### GPL v2 source offer

`web/` serves GPL v2 binaries we did not write: FTEQW's `ftewebgl.js` /
`ftewebgl.wasm`, and id's QuakeC as `progs.dat` / `qwprogs.dat`. GPL v2 s.3
requires the corresponding source to be offered alongside the binary, so
`web/SOURCE.md` is that offer: the exact upstream commits, the build scripts,
and the build flags (including the `EXPORTED_RUNTIME_METHODS` `LDFLAGS` the web
link needs). It is linked from the page footer and generated by
`scripts/gen_source_md.py`, so it cannot drift from the pins;
`tests/run_fte.js` phase 3 fails if it does. Our own QuakeC from M4 onwards is
covered by the same file.

## Deliberately NOT used

Never fetched, never copied, never shipped:

- Quake / QuakeWorld **game data** (`pak0.pak`, `pak1.pak`) — id / ZeniMax /
  Microsoft. Shareware `pak0.pak` may be used **locally only**, as a test
  oracle, in git-ignored `local-assets/`.
- **Team Fortress** QuakeC, models, sounds or maps (including 2fort5) — Team
  Fortress Software, acquired by Valve; no open licence. Not ported, not
  copied.
- The names **"Team Fortress"**, **"TF"**, **"2fort"** — Valve trademarks. Our
  game, class and map names are our own.

## Our own generated assets

`scripts/gen_assets.js` and anything it emits are ours. Note that the previously
generated `2fort5.bsp` is retired with the custom engine (see
`.team/PLAN.md`): it was a 2fort5-*style* layout, and the shipped map must be an
original design, not a recreation. New maps are authored as `.map` sources in
`maps/` and compiled with ericw-tools.
